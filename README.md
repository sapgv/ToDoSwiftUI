# Приложение Список задач

## Установка
* Скачать проект
* Выполить команду
  ```
  pod install
  ```

## Фичи
* Загрузка задач
* Отметка о выполнении из списка
* Создание новой задачи
* Обновлении существующей задачи
* Удаление задачи

## Core Data
* Для базы данных используется Core Data. Для создания, редактирования и удаления объектов используются BatchRequest, потому что это самый быстрый способ создать и обновить данные. 
BatchRequest имеет тонкости и ньюансы (например нет проверки валидации или обновления relationship), но в рамках этого ТЗ этого не требовалось.
* Для сущности CDTodoItem добавлены constraints - uuid. 
Это позволило всегда создавать объект без предварительного fetchRequest для поиска существующего объекта.
Будьте внимательны при использовании constraints - нужно всегда учитывать NSMergePolicy.

## Архитектура
Используется SwiftUI. Можно было использовать UIKit, но интересно было попробовать SwiftUI. 
Бизнес логика вынесена в сервисы TodoFetchService и TodoStorage и при желании можно перейти на другую архитектуру с использованием этих сервисов.

## Многопоточность
Для многопоточности использовал Structered concurrency. Core data полностью поддерживает Structered concurrency. Именно поэтому в проекте нету GCD и NSOperation.

## Тесты
Используется Quick и Nimble. Для генерации моков Sourcery.
На сервисы TodoFetchService и TodoStorage написаны тесты.
